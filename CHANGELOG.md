### Changed
- The confidentiality gate fails closed (#98). With `GATE_REQUIRED=1`, which `check.yml` sets on every deploy run (push, schedule, dispatch, through `workflow_call`) and on same-repo pull requests not opened by Dependabot, no patterns, fewer than the minimum (10, or the `CONFIDENTIAL_PATTERNS_MIN` variable) or no git exits 1; the optional `CONFIDENTIAL_PATTERNS_SHA256` variable pins the list's fingerprint, and a mismatch exits 1 without printing either hash. `node scripts/gate.mjs --fingerprint` prints the count and the fingerprint. The tree scan now covers every tracked file (`git ls-files -z`) plus `dist/`, not only `dist/`, `src/` and `docs/`, and every pattern is also tested against each file's path, printed as `<path>: pattern #<n> (path)`. Deliberate mentions go in the committed `.gate-allow` (exact pattern number, scope and path, with a reason); a malformed or stale entry fails. `--staged` (the pre-commit hook) matches paths too and honours the staged `.gate-allow`, without the stale check. ADR 0005 gains an amendment; README Checks rewritten.
