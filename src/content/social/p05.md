MTS Hub, the operations platform I build, has a second brain now, and agents maintain it.

The loop:

I send a voice note on Telegram.
A self-hosted speech-to-text service transcribes it.
An agent pulls out the concepts and links them into a Markdown vault: products, capabilities, offers, ideas, with typed relations between them.
A read-only 3D graph app lays the vault out (UMAP) so I can see what connects to what. Open GitHub issues show up as satellite nodes on the concepts they belong to.

Claude Code reads and writes the vault over MCP, so the same knowledge is there when I'm planning work.

Hub's records hold what the company does. The second brain holds what it is thinking about.

Two decisions made it work. The domain language (Vault, Concept, Utterance) was written down before any code. And the graph app is strictly a read-only consumer. Only one thing writes to the vault, so the vault stays the truth.

It's small: 18 commits, five ADRs.
